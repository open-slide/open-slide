## Fullscreen playback

From the dev server, hit **Present** (or press `f`). The current deck goes
fullscreen, scaled uniformly to fit the screen:

- Arrow / space / `PgDn` to advance.
- `←` / `↑` / `PgUp` to go back.
- `Home` / `End` to jump to first / last.
- `Esc` to leave fullscreen and continue presenting in the same tab. Press
  `Esc` again in windowed mode to end playback.

## Presenter view

Press `p` (or the presenter button in the present control bar) to open the
presenter view in a second window:

- **Current slide** at the size you'll show it.
- **Next slide** preview.
- **Speaker notes** for the current page.
- **Timer** — elapsed time since you entered present mode.

Keep it on the laptop screen while the deck mirrors to the projector.

## Speaker notes

Add notes alongside the page array — an array of strings, index-aligned with
the pages (use `undefined` to skip a page):

```tsx
export const notes = [
  'Open with a smile. Mention the analyst quote from yesterday.',
  undefined,
  'Pause here for questions. The chart is a hand-off.',
];
```

## Embedding

Open the link menu in the slide toolbar to share a playable copy of the deck:

- **Copy embed link** — paste it into Notion (choose **Create embed**), Slack,
  or any app that embeds links.
- **Copy embed code** — a responsive 16:9 `<iframe>` for websites and blogs.

The embed (`/s/<slide-id>/embed`) is a bare player: click the edges, swipe, or
use the arrow keys to move through pages, with a small control bar for
fullscreen and opening the full deck in a new tab. Add `?p=3` to start on a
given page.

Embeds need a deployed deck — a `localhost` link only works on your machine.
