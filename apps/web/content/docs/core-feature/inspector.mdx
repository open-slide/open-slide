title: Inspector

![Open-slide inspector with the property panel docked beside the canvas, editing a selected element's typography and colour](/assets/screenshots/inspector.webp)

The visual editor is available during development. Slides open in edit mode:
click an object to select it, drag to move it, and double-click text to edit it.
Press `Enter` to edit a selected text object. Press `Escape` to return to object
selection, then again to clear the selection.

The **Format** toolbar button (or `i`) shows and hides the property panel.
On desktop, the panel stays open while you select different objects or clear
the selection, keeping the canvas in the same position. Drag the panel's inner
edge to make it wider; double-click the edge to reset it. Format, Design, and
the agent panel share this sidebar, so opening one closes the others.

Choose **Preview** to interact with the slide and play its animations, then
**Edit** to resume editing. **Present** opens presentation mode.

## Add slides and objects

In edit mode the toolbar shows **Text box**, **Shape**, and **Image** buttons.
Each adds the object to the current slide, centered and selected, using the
deck's [design tokens](/docs/core-feature/themes) for color and type. Shapes
come from a menu of rectangles, ellipses, polygons, stars, arrows, callouts,
and lines, and are written as the [`<Shape>`](#shapes) component. Image opens
the asset picker; you can also drop an image file anywhere on the canvas, or
paste one from the clipboard.

The **+** button above the page thumbnails adds a slide after the current one.
Pick a layout — blank, title, title & body, section, two columns, image &
caption, or quote — and the new slide opens with every element ready to move
and restyle. With nothing selected, the Format panel's **Slide** section sets
the slide's background color.

Copy, cut, and paste work on selected objects. Pasting on the same slide
offsets the copy; pasting on another slide keeps its position. Copied objects
also reach the system clipboard as JSX, and pasting JSX or plain text from
elsewhere creates the matching element.

## Arrange objects

Click an element to select it. Drag the selection to move it, use its handles
to resize it, or drag the rotation handle. Smart guides appear when an edge
or center lines up with another element or the slide. Positions and sizes
use slide pixels, so the same movement works at any canvas zoom.
Rotated elements scale proportionally when their width and height cannot be
adjusted independently without distorting the shape.

The **Arrange** tab provides exact position, size, and rotation inputs,
plus alignment and layer controls:

![Open-slide Arrange tab showing position, size, rotation, align, and layer controls for a selected headline](/assets/screenshots/inspector-arrange.webp)

- **Align** — align left, center, right, top, middle, or bottom. Choose the
  slide or the combined selection as the reference.
- **Distribute** — select at least three elements to give them equal gaps
  horizontally or vertically.
- **Layer** — bring forward, send backward, bring to front, or send to back
  within the element's CSS stacking context.
- **Smart guides** — toggle snapping, or hold `Alt` to bypass it temporarily.
- **Select parent** — move up to the containing element to arrange a whole
  component, card, or text block. Hold `Cmd` / `Ctrl` while clicking to select a child
  inside an already selected container.
- **Group** — combine two or more freely positioned objects so they select and
  move as one; ungroup to split them again. Click a group to select it and
  `Cmd` / `Ctrl`-click to reach an object inside.
- **Lock** — keep an object from being moved, resized, deleted, or grouped by
  accident. Locked objects can still be selected and formatted.

Hold `Shift` while clicking to add or remove elements from the selection.
Drag the combined selection to move all selected elements together. Drag on
empty canvas to select elements with a marquee. **Select all** selects the
slide's editable elements without selecting both parents and their children.
Width, height, and rotation inputs apply to one element at a time.

| Shortcut | Action |
| --- | --- |
| `Enter` with a text object selected | Edit its text |
| `Escape` while editing text | Return to object selection |
| `Escape` with an object selected | Clear the selection |
| `I` | Show or hide the Format panel |
| Arrow keys | Move the selection by 1 slide pixel |
| `Shift` + arrow keys | Move by 10 slide pixels |
| `Shift` while dragging | Constrain movement to one axis |
| `Shift` while resizing | Preserve the aspect ratio |
| `Alt` while dragging | Temporarily bypass smart guides |
| `Shift` while rotating | Snap to 15-degree increments |
| `Escape` during a drag | Cancel the current gesture |
| `Cmd` / `Ctrl` + `A` | Select all editable objects |
| `Delete` / `Backspace` | Delete the selection |
| `Cmd` / `Ctrl` + `D` | Duplicate the selection |
| `Cmd` / `Ctrl` + `C` / `X` / `V` | Copy, cut, and paste |
| `Cmd` / `Ctrl` + `Alt` + `G` | Group |
| `Cmd` / `Ctrl` + `Alt` + `Shift` + `G` | Ungroup |
| `Cmd` / `Ctrl` + `L` | Lock or unlock |
| `Cmd` / `Ctrl` + `Z` | Undo |
| `Cmd` / `Ctrl` + `Shift` + `Z` | Redo |
| `Cmd` / `Ctrl` + `S` | Save now |

Inline text spans inherit their containing block's layout. Use **Select
parent** to move that block. Elements rendered repeatedly from the same JSX
definition also share source styles; select a unique parent container to
arrange, delete, duplicate, or group an instance independently. The panel explains when a selected element
cannot be transformed.
Layer changes preserve nested content's position and size. If shared nested
content prevents this, select a positioned parent container to change layers.

## Format text and images

The Format panel shows controls for the selected object. Use the **Text** tab
for font, typography, text colour, and paragraph alignment; the **Image** tab
for replacement and cropping; and **Style** for a shape's appearance. Every
object also has an **Appearance** section for opacity, corner radius, border,
and shadow. Switch to **Arrange** for geometry, alignment, and layers. With
several objects selected, colour and appearance changes apply to all of them.

Select a word or phrase directly on the canvas, then change its size, weight,
style, or colour in the panel. The selection stays active so you can continue
typing or apply another format. `Cmd` / `Ctrl` + `B` and `Cmd` / `Ctrl` + `I`
toggle bold and italic while editing text. When the panel is hidden, a compact
toolbar provides the same text controls beside the selection.

Line height and letter spacing sit in the **Typography** section, and
**Content** lets you edit the object's complete text in a text area. The
expandable **Source** section at the bottom shows the element tag and agent
connection. Notes for your agent live in [comment mode](#comments).

Image replacement lets you choose any file in the deck's or the global assets
folder; see the [assets manager](/docs/core-feature/assets-manager) for how the
two scopes work.

Edits save to source automatically once you pause, and right away when you
switch to Preview or leave the deck. Undo and redo keep working after a save,
including for added, deleted, and grouped objects. If the file changes outside
the editor in the meantime, undo stops at that point rather than overwrite it.

## Shapes

Shapes are written as the [`<Shape>`](/docs/primitive/shape) component from
`@open-slide/core`, so the source stays readable for you and your agent:

```tsx
<Shape
  kind="star"
  fill="var(--osd-accent)"
  stroke="#111111"
  strokeWidth={4}
  style={{ position: 'absolute', left: 780, top: 360, width: 360, height: 360 }}
/>
```

Select a shape to change its **Type**, **Fill**, **Stroke**, and stroke
**Width** in the Format panel. Lines and arrow lines are horizontal; use the
rotation handle for other angles.

## Comments

Sometimes the change is easier to describe than to perform. Switch to
**Comment** mode in the toolbar (or press `c`), then click an element — or
drag across a region of the slide — and type a note:

> use the accent colour on this title

![Open-slide comment mode with a note being written on a selected headline](/assets/screenshots/comment.webp)

Press `Cmd` / `Ctrl` + `Enter` to post it. The note is written to the source
right away as an `@slide-comment` marker. A region note attaches to the
smallest element that contains the region. The marker travels with the
element and is invisible at runtime.

Posted notes stay pinned on the canvas while comment mode is on. Click a pin
to edit or delete its note. The Comment button shows how many notes the deck
has, and the bar under the canvas reminds you to apply them. Press `c` or
`Escape` to leave comment mode.

Run `/apply-comments` in your agent to turn the notes into edits — see
[`/apply-comments`](/docs/skills/apply-comments). With the
[agent panel](/docs/core-feature/agent) connected, click **Apply with Claude
Code** (or Codex) in that bar instead.

## Selection is visible to your agent

Whenever you click, the inspector publishes the picked element to a file
your agent reads via [`/current-slide`](/docs/skills/current-slide) — so
*"make this bigger"* resolves to the exact JSX node with no "which one?"
round-trip.
